Six clinical use cases (soft-tissue split by language into seven datasets), each showing all 15 models grouped by size category. Bar color = model size tier. Marker shape = prompting strategy. Dashed lines = inter-rater agreement (human baseline) where available.

Use Case Variance
Performance varies dramatically — Colorectal Liver Mets and Neurodegenerative Diseases score ~0.8+, while Sarcomas (Czech) drops to 0.3–0.5
Size ≠ Dominance
Small/medium models (especially Mistral Small 3.1 24B) are competitive with large models in most use cases — size alone doesn't guarantee top performance
Language Effect
Sarcomas (Czech) shows the steepest performance drop across all models, suggesting non-Dutch/English reports are significantly harder to extract from

Discussion Points

Key Finding

Small Models Punch Above Their Weight

Mistral Small 3.1 (24B) ranks #1 overall despite being 28x smaller than DeepSeek R1 (671B). Size is not the primary driver of extraction performance.

Statistical Caveat

Overlapping Confidence Intervals

No model is statistically dominant — the top 4 models' 95% CIs overlap substantially, meaning rank differences may not be meaningful.

Surprising Result

Medical-Specialized Models Underperform

Med42, OpenBioLLM, and MedGemma all scored below general-purpose models. Domain-specific fine-tuning may hurt structured extraction.

Methodology

Kemeny-Young vs Mean Ranking Disagree

Mistral ranks #1 by Kemeny-Young but #2 by mean macro-average. The aggregation method changes the winner.

Scaling Threshold

Sharp Performance Cliff Below 4B Parameters

Models under 4B parameters (Gemma3 4B, Qwen3 1.7B, DS-R1 1.5B) show a dramatic drop-off in extraction quality.

Critique

Most Performance Variance Is Unexplained

Model choice explains only 18–37% of variance. Prompting explains 0.2–35%. The remaining 45–80% is residual — "your mileage will vary."
